# 2330 衝動轉換器

想買東西之前，先把價格換算成台積電（2330）：

- 這筆錢現在能買幾股（零股）
- 放 10 年、用不同年化報酬會變成多少
- 「忍住清單」：記下每次忍住或沒忍住，看累積了多少、少賺了多少
- 退休金目標：照目前忍住的速度，多久能存到目標金額（預設 2,000 萬）

👉 使用網址：**https://nekogugoru.github.io/tsmc-impulse/**

## 加到手機主畫面

- **iPhone（Safari）**：打開網址 → 下方分享按鈕 → 「加入主畫面」
- **Android（Chrome）**：打開網址 → 右上角 ⋮ → 「安裝應用程式」或「加到主畫面」

加到主畫面後，用起來就像一般 App，沒有網路也能開（股價會顯示最後一次抓到的收盤價）。

## iPhone 主畫面小工具（不用開 App 就能換算）

用 iPhone 內建的「捷徑」App 做一個小工具：點一下 → 跳出數字鍵盤 → 直接顯示結果。

**建立捷徑**（捷徑 App → 右上角 ＋，依序加入動作）：

1. **要求輸入**：類型選「數字」，提示文字「想買的東西多少錢？」
2. **設定變數**：名稱「價格」
3. **取得 URL 內容**：網址填 `https://nekogugoru.github.io/tsmc-impulse/data/2330.json`
4. **取得字典值**：取得「值」，鍵填 `close`
5. **設定變數**：名稱「股價」
6. **計算**：價格 ÷ 股價 → **四捨五入數字**（小數點後 2 位）→ **設定變數**「股數」
7. **計算**：價格 × 2.5937 → **四捨五入數字**（個位數）→ **設定變數**「十年後」
   （2.5937 = 年化 10% 的 10 年倍數；年化 6% 用 1.7908、15% 用 4.0456、29% 用 12.7614）
8. **顯示提醒**：
   標題「NT$ 價格 = 股數 股 2330」
   內容「股價 股價 元｜10 年後（年化 10%）約 NT$ 十年後」
   （標題和內容裡的「價格」「股數」「股價」「十年後」，要從鍵盤上方的變數列點選插入，不是直接打字）

捷徑命名「2330 換算」，圖示選錢幣、顏色選金色。

**放到主畫面**：長按主畫面空白處 → 左上角「編輯」→「加入小工具」→ 搜尋「捷徑」→ 選小型（佔 4 個 App 的位置）→ 點小工具選「2330 換算」。

**分享給同事**：在捷徑 App 長按「2330 換算」→ 分享 →「拷貝 iCloud 連結」，同事點連結就能直接加入。

## Android

長按主畫面上的 App 圖示，會出現「快速換算」，點了直接進入輸入。也可以把「快速換算」拖到主畫面成為獨立捷徑。

## 股價怎麼更新

`.github/workflows/update-price.yml` 會在每個交易日台北時間約 14:20 和 16:20 執行 `scripts/fetch_price.py`，從臺灣證券交易所抓 2330 最新收盤價，寫入 `data/2330.json`。

- 當天還沒收盤或休市：維持前一個交易日的收盤價
- GitHub 的排程偶爾會延遲幾十分鐘，屬正常現象
- 想立刻更新：到 repo 的 **Actions → 更新 2330 收盤價 → Run workflow**

## 資料隱私

忍住清單和目標金額只存在使用者自己手機的瀏覽器裡（localStorage），不會上傳到任何地方。
換手機或清除瀏覽器資料前，請先按「匯出備份」，之後在新手機按「匯入備份」。

## 計算方式

- 可買股數 = 價格 ÷ 最新收盤價（無條件捨去；不足 1 股顯示小數）
- 10 年後 = 價格 ×（1 + 年化報酬）¹⁰
- 至今價值 = 金額 ×（最新收盤價 ÷ 記錄當時股價），未含股息
- 達標時間：把「忍住總額 ÷ 第一筆忍住至今的月數」當作每月投入，以年化報酬按月複利推算
- 「台積電過去10年 29%」依 2016→2026 股價估算、未含股息；過去績效不代表未來
- 未計手續費與證交稅

> 本工具僅供自我提醒，不構成投資建議。
